# #welcome (paste as the first message)

**d.idle** is an open-source bot that plays one Diablo II: Lord of Destruction 1.14d character, offline single player, on a game
you own and run yourself, plus an idle-game layer on top (parked until the bot plays well). It is written in Go.

- Start here: the README in the repo (GitHub: shatteredeagle/d-idle), then `docs/quickstart.md` and `docs/container.md`.
- Where things are: `docs/INDEX.md`. What works today: the Status section of the README and `docs/plan/STATUS.md`.
- Honest status: early and measured. We tag claims verified or unverified. The README is the one source for what is proven; we link
  it here instead of copying numbers, so this text does not go stale.
- AI agents write most of the code from written briefs (see `AGENTS.md`). Humans review, decide and moderate.
- No game files, keys or cracks here, ever; you bring your own install. Offline only, no Battle.net.
- Not affiliated with or endorsed by Blizzard Entertainment.

Channels: `#rules` first, then the FAQ pinned here. Help: `#help`. Bugs: `#bug-reports`. Progress feed: `#progress`. Chat: `#general`.
Related community: the d2d (d2decomped) project, the open-source engine we run on, has its own space; we are separate.
