### Breaking down "equal" (V run, a read-only script over the same files)

`compare` counts a start as equal when `0 <= len(game) - len(tick) <= 2 and game[k:] == tick`. With an **empty** tick path (the walker reached the end in the first tick, or the tick cleared the path) that holds for any game.exe path of 0 to 2 points, so it is equal by default:

| claim run | tick path empty, counted equal | of those, game.exe had 1 or 2 points | tick path visible and equal | visible, equal, and the spot plan differs (discriminating) |
|---|---|---|---|---|
| `--dump 30` | 242 | 88 | 20,734 | **469** |
| wide | 425 | 123 | 39,570 | **537** |

So about 211 starts (88 + 123) of the "60,955 equal" are starts where game.exe planned 1 or 2 points and d2d's plan is not visible; 456 more are empty on both sides. The parent shows the same empty-path counts, so this does not favour the claim; but these starts check nothing about the plan, and 4 of them (d30) are starts where the spot plan differs.
