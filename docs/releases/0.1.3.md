# d.idle friends release 0.1.3

> status: BUILT, DRILLED AND STAGED 2026-11-15 (card cut013), NOT PUBLISHED. It supersedes 0.1.2, which was built and drilled but never published and must not be. Cut from main `dfdc3d29e` (CI green) plus this card; repo commit `e57a3a26bbc0` (clean tree) is what the pack and the update set ship. Tags: V run and seen, S read or tested offline, U not run. The previous releases are docs/releases/0.1.0.md, 0.1.1.md and 0.1.2.md.

## What changed for friends (plain words, since 0.1.1)

- **A new watch page, the cockpit, is the default.** A status band on top, the map and the hero's panels around it, a character screen with the inventory, and a phone layout: the page fits a phone held upright. **The way back to the old page:** open `/watch?layout=classic`, or use the menu at the top right: Menu, then Layout, then Classic (the menu also offers Simple, Standard, Stream and Debug). The choice is remembered in the browser.
- **A Reset button** (Menu, then "Reset (leave the game and rejoin)", with a confirm sheet). The hero leaves the game at a safe moment and joins a new one with the same character; the plan, orders and pause stay. A "Needs you" row offers it when the hero looks stuck. A real press in the drill took 21 s and the hero went on fighting (V).
- **Fewer stuck steps.** A step the hero cannot finish is parked and the plan moves on (it used to wait forever); the object finder now explores until the object shows up (for example the Inifuss tree); the bounce loop at warps, the stale target and the blocked-quest fallbacks from 0.1.1 and 0.1.2 are all in.
- **Safer defaults.** The portal guard and the new farm loop (reset a mostly cleared zone with a fresh game) are OFF by default. `GET /api/zoneclear` shows the explored-share setting and its siblings with range and default.
- **Under the hood:** a survival model runs in shadow (it records what it would pick and does not steer), hero power data, a merc revive on gold alone, loot rules, level plan v3, sell and swing fixes.
- **Installer** (from 0.1.2): a game folder with a space in its name (the default "Diablo II") works; pointing `--game-dir` at the unzipped download finds the `Diablo II` folder one level down; only the data archives are mounted into the container, read-only, one file each, so your key file, the game program and your saves never reach it (`ls /game` inside the container shows nine archives, V).
- **README:** check the tarball with its own `.sha256` file before you unpack it.

The d2d engine is unchanged: fork `acadbe47f989` (branch `fork-only/art-clean`, still the tip of that branch on the private forge, V), byte-identical binary (sha256 `1a642471cdcd5539ef01a7c9518e4a0e9f734561570012d5d6fa4e2bd960f99e`) and the same source tarball as 0.1.0 to 0.1.2. The lab verbs and item verbs of the sandbox forks are not in it; the friends image plays through ordinary clicks (item verbs default 0).

## Known limits

- Everything in docs/releases/0.1.1.md still holds (Sacrifice is live-unverified, a release counts as healthy after 10 minutes, Linux and Docker only).
- 0.1.0 and 0.1.1 clients apply an update at once without the safe-spot check of newer clients; update while the hero stands in town. A friend whose game folder has a space edits `.env` once (`D2_GAME_DIR='/path/with space/Diablo II'`) or reinstalls from the new pack.
- Screenshots of the cockpit at desktop and phone size were not taken: no browser could reach the drill container (the pack publishes on loopback only). The page and its layout were fetched and read, not looked at (U).
- One drill WARN was seen twice: `portal click did not change the level` on a return trip; the hero recovered.
- The in-app `./didle update` prints "applied" even after a refusal; read the JSON line above it.

## How a friend updates, installs, and what to tell them

- A friend on 0.1.0 or 0.1.1: the watch page shows an update banner (Update button), or run `./didle update` and answer y while the hero stands in town. The image is not changed (abi 1). The new page appears after the restart; the old one is `/watch?layout=classic`.
- A new friend: `sha256sum -c didle-friends-0.1.3.tar.gz.sha256`, `tar xzf didle-friends-0.1.3.tar.gz`, `cd didle-friends-0.1.3`, `./install.sh --game-dir '/path/to/your/Diablo II'`, open the printed address, pick a hero, start. Ports 8891 and 8892, 3 GB free, your own Diablo II 1.14d files.
- Message for friends: "0.1.3 is out: a new page layout (the old one is Menu, Layout, Classic, or add `?layout=classic` to the address), a Reset button for a stuck hero, fewer stuck steps, a safer installer that only shows the game archives to the container. Update from the banner while your hero is in town. Same rules as before: private test, offline, your own game files, the address with the token is your password."
