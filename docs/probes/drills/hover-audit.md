# Hover blind-spot audit (agent DRILLS3, 2026-10-31, card m1-liveproof)

> status: current. Why: under the lab's `--lockstep` d2d resolves "what is under the cursor" only while it draws a frame and lockstep draws none, so a hover plus click on a world object just WALKS (docs/d2d-portal-entry.md). This lists every bot verb that clicks or hovers, how it works under lockstep, and which ones are at risk. Live proofs are drill group `H` (`2026-10-31-h.txt`) and `D3`, `D4` (same folder); every result ran twice, identical. Nothing was fixed here; the fix queue is the last column.
