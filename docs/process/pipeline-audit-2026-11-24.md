## Top 5: patch outlines

### 1. Stop silent timer failures (rows 1, 21)
- One-time (user or coordinator, after checking no publish runs): `rm ~/d2lod-status/pages-clone/.git/refs/heads/main.lock`.
- push_pages.sh: before git work, remove `*.lock` files in the clone older than 30 min when no git process for that clone runs; print what it removed.
- tools/nightly_race.py: an idle reading below 0 is "measure failed": log it and exit 1 (not "skipped tonight" with exit 0); after 2 skipped nights in a row exit 1 too.
- Every `d2-*.service`: `OnFailure=d2-alarm@%n.service`; `d2-alarm@` writes the needs-you tile and the board hub note (one line per unit per day, de-duplicated).

### 2. Auto-Done for superseded heads (row 2)
- mergeq.py, where pending ci is resolved: when a head's run is `cancelled` because a newer run of the same workflow started, keep it pending; when a LATER head turns green and contains it (`git merge-base --is-ancestor`), resolve it to `green (via <later head>)` and call `auto_done(it, res)`.
- `mergeq add`: when `--card` matches no `backlog/tasks/*` file, refuse with "no task for card X" (the queue already knows the card).
- Then `tools/mergeq.sh auto-done-scan --since 2026-11-10 --apply` once, and check `drift.py --summary` drops.

### 3. Timing-test policy (row 3)
- Rule for agents (AGENTS.md "Keep code idiomatic" section, coordinator edit): no wall-clock ceiling (`time.Since`, `NsPerOp`, a `Millisecond` bound) in a test that runs by default. Use the fake clock, a ratio against a baseline measured in the same test, or put it behind `//go:build perf` (run nightly on the builder) or `if raceOn { t.Skip }` (the `race_on_test.go` pattern already exists in cmd/d2dview and on agent/toolstrade44).
- merge.sh: apply the known-flaky re-run to go-race as well as go-whole.
- `TestPlayerResetStartsOnTheNextTick`: card to make the loop step the fake clock deterministically, or list it in flaky.txt with its measured rate until then.
- Tests to review against the rule (V, grep of `_test.go` for a time bound): internal/watch/vaultperf_test.go:105 (10 ms), internal/watch/vaultapi_test.go:164 (150 ms), internal/loot/lootshadow_test.go:286 (1 ms per item), internal/art/speed_real_test.go:68 and 73 (5 ms, 2 s), internal/nav/plan_test.go:246 (10 s), internal/nav/walksmooth_test.go:25 (500 ms), internal/bot/leveling_test.go:187 (10 s), internal/d2dtown/adapter_wait_test.go:25 (100 ms), internal/d2dctl/client_test.go:236 (350 ms), internal/d2dctl/fixstall4_test.go:188, internal/d2denv/freeze_test.go:77 (25 ms), internal/d2denv/waits_test.go:38, internal/d2denv/fixobj_test.go:87, internal/watch/videoresume_test.go:57, cmd/d2dview/view_test.go:275 (500 ms), cmd/d2dview/pacing_test.go:67 and 108 (15 ms). Some of the d2denv/d2dctl ones may skip without a game (U); the generous ones (10 s) are low risk.

### 5. Ownership and guarded paths at preflight (rows 5, 15)
- merge.sh `pf_run`: `ownscheck`: the branch diff minus the generated files (BACKLOG, CHANGELOG, INDEX, OWNERS, STATUS block, cards) must match the card's `owns:` prefixes; a miss is a WARN for one week, then a failure.
