# Monster skill use for the Act 1 and 2 casters and shooters: game.exe 1.14d vs d2d vs our bot (card monsterskill, 2026-11-02)

> status: research, current. Question: which skill does a monster use and when (the Skill1..8 slots with Sk*mode and Sk*lvl, the use probabilities and ranges, delay and cooldown by difficulty, mana, line of sight), and what missile or state comes out, for the Act 1 and 2 shooters and casters. Tags: **V read** read in the game.exe disassembly (`tools/emu/mai2_dis.sh`, upstream's `disasm.py`; address and instructions given); **V run** game.exe's own code run under the emulator (counts below); **D** a 1.14d patched table (`tools/emu/mpq-table.sh`); **S** an existing trace or upstream proof (named); **I** inference; **U** unverified. d2d = upstream f8aab0e8 (`components/rules/monsters.hpp`, `components/game/ai.cpp`; scratch tree on the worker host, read only). Offline only: no game, no d2d slot, nothing pushed or posted. Builds on docs/research/monster-ai-trace.md (the thinks), monsterai2-trace.md (Fallen Shaman, Skeleton Archer), monster-missile-trace.md (the missile record) and sk-mana-trace.md (mana, delay).

## Verdict

1. **A monster has two ways to hurt from range, and the choice is in the think, not in a probability table.** The shooters (Skeleton Archer, Corrupt Archer family, Quill Rat family, Bighead, Skeleton Mage, Sand Maggot) have NO skill slot: they fire the missile named by the monstats column MissA1 / MissA2 in the attack mode (D). The casters (Fallen Shaman family, Greater Mummy) fire through a skill slot (Skill2 / Skill3, srvdofunc 85) in the SQ mode with a MonSeq sequence (D). Which one, and how often, is the AI function's own code with the aip1..aip8 columns as thresholds (V read; V run in the earlier traces and here).
2. **Skill slots are loaded once, at spawn, and a slot with Sk*lvl 0 does not exist.** `FUN_00573cb0` (0x5740e0..0x574135): for each of 8 slots, id word below 0 or level byte at or below 0 skips the skill; the level is `Sk*lvl + DifficultyLevels MonsterSkillBonus` (0 / 3 / 7). **V run: 216 slot cases (72 slots on 3 difficulties), 0 differ** from `Sk*lvl + 0 / 3 / 7`, read back from real spawned monsters with game.exe's own skill lookup and level function. d2d's `monster_skill_level` is the same arithmetic (V read of its 4 lines; the d2d code itself was not called, S/I).
3. **A monster casts for free.** game.exe's mana check (`FUN_0056c160`) and payment (`FUN_0056bfe0`) both return 1 / nothing for a unit that is not a player. **V run: 42,840 cases (all 357 Skills rows x levels 1..60 x mana 0 and 0x20000) for a monster unit: 0 refused, 0 paid; the player control on the same cases refuses 9,697 and pays on 9,847.** There is no monster skill delay either (`FUN_0056ef90` is players only: S, sk-mana-trace). A monster's only cooldown is its think period `aidel` (15 / 14 / 13 frames for every Act 1 and 2 caster and shooter row, D) plus the animation it is in.
4. **Corrupt Archer family (Dark Ranger, Vile, Dark, Black, Flesh Archer; Coldcrow): d2d's think equals game.exe: 3,000 cases (seeds 20261102 and 7), 0 differ** (V run, first run of this AI; ledger row added). The two other archer / shaman / rat thinks were already 0 differ (S: Skeleton Archer 3,000, Quill Rat 3,000, Fallen Shaman 1,500 + 12,000 corpse candidates with one reach deviation).
5. **No line-of-sight test sits in the shooters' thinks** (V read: the Corrupt Archer's calls are the target search, circle, stand, got-hit, mode, pace, back-off, approach, run, skill: no sight function); the only line test among the Act 1 / 2 skills is the Fallen Shaman's Resurrect at its corpse (`FUN_005fd470`, mask 0x3c01) and the Sand Leaper / Claw Viper tests (D1 below). d2d feeds "a skill is always usable" (ai.cpp:901-902), so D1 is a read-only deviation, effect U.
6. **Bot: 20 of the 53 missile-firing Act 1 / 2 rows have `rangedtype` blank, so the bot treats them as melee** (B1): the four Fallen Shamans (Bishibosh is one), Sand Maggots, Greater Mummies, Radament, Andariel, Blood Raven, the Summoner and the Dark Stalker; the shooter-peak model is in percent units and cannot see their fire (B2, B3).
7. **No PR candidate** (D1 is read only; nothing in this card is a proven d2d deviation).

## Bot findings (described, not changed; effects UNVERIFIED)

- **B1: `rangedtype` is the bot's whole notion of "shooter", and 20 of the 53 missile-firing Act 1 / 2 rows leave it blank** (D, `tools/emu/msk_bot.py`): Fallen / Carver / Devilkin / Dark / Warped Shaman (fire, Skill2), Sand Maggot 1..3 (spit), Greater Mummy / Unraveler 1..3 and Radament (spit and UnHolyBolt), Andariel, Blood Raven, the Summoner, Dark Stalker (Countess Firewall, data only: Q7), the two Panther pots and the Sand Leapers (a leap, not a shot). `data.Monster.Ranged` is `r.Bool("rangedtype")` (internal/data/monsters.go:122). Consequences by reading: `kiteThreats` counts a Fallen Shaman as a melee threat (internal/combat/fight.go:782 skips only `Ranged`), so a shaman 15 subtiles away can arm the stepback / kite rules meant for melee packs; the autopsy calls a shaman kill "melee" (internal/bot/autopsy.go:193); `ShooterPeak` returns 0 for them (internal/combat/threat.go:149). Whether a kite or stepback is wrong against a shaman is U (drill S2).
- **B2: `ShooterPeak` is in the units of the column, not in points** (internal/combat/threat.go:152-157). For a ratio monster A1MaxD / A2MaxD / S1MaxD are percents of the monster-level damage (S monster-attack-trace; D here): sk_archer1 reads 90 / 50 / 50 and Quill Rat 101 / 75 / 75 while the real top hits are 3 / 16 / 39 and 2 / 23 / 57 points (L-DM x percent, `tools/emu/msk_bot.py`; game.exe's missile record for the same rows, monster-missile-trace Q4: skbowarrow1 2-3 / 10-15 / 26-38, spike1 1-2 / 19-26 / 44-61). Its documented knob `ShooterKillMin` is in "pts" (internal/env/tuning_combat.go:145, range 0..200, default 0 = off), so any non-zero setting compares percent with points. The elemental slot reads only the base-difficulty column (`El1MaxD`, internal/data/monsters.go:149), so Nightmare / Hell elemental peaks come out as the Normal ones.
- **B3: `unblockable` (internal/combat/threat.go:158) is "physical column is 0 and an El column is set", which is true for 11 Skeleton Mage rows only**; the rows whose MISSILE has no physical part but whose attack columns do (Bighead 4, Fallen Shaman 4, Greater Mummy 3 + Radament; monster-missile-trace Q5: the can-block gate is the missile's own record, V run) read as blockable, and the shamans are excluded earlier by B1. Effect on `KillFast` (internal/combat/target.go:223) U while `ShooterKillMin` is 0.
- **B4: nothing models a shooter that keeps its distance.** The Corrupt Archer backs off 12 running when the target is under 6 subtiles at aip4 % (20 / 30 / 40 for cr_archer1) per think and approaches only to aip8 = 12; the Skeleton Archer keeps aip5 off past 19 (Q7). The approach budget (`MaxApproaches` 12, `ReachSec` 15, internal/combat/fight.go:487) counts a target that does not close or stays at range as "never in range"; for the archers that is the normal rule, like the Fallen's stand (monster-ai-trace B3, S). Effect U.
- **B5 (no change needed): mana-less casting.** Nothing in the bot's threat model charges a monster mana; the Q8 run says that is right.

## Dead ends and limits

- First Corrupt Archer run: 551 of 1,500 "skill vs run". Cause: upstream's `mon_ais.py` hooks `FUN_005ded40` as run but not `FUN_005defb0`, which the Corrupt Archer calls; the real `FUN_005defb0` reached `FUN_005dead0` and the harness labelled the run a skill. Hooked in `tools/emu/msk_ais.py` the same way as `FUN_005ded40`. Second run: 176 of 1,500 differ in the step count only (n 1 against 0): `FUN_005defb0` turns `n == 0` into 1 internally; the aip5 column is 20 in every row (D), so the scene's random aip5 = 0 is unreachable; with the count as the think passes it (`MSK_RAWN=1`, default): **0 of 1,500, twice**. The labels and the normalisation are stated, as in monsterai2: the second target equals the primary at the same distance (what ai.cpp feeds).
- `SkillDamage` (monstats) is set on four rows, all Druid pets (D, `awk` over the table): not a source for any Act 1 / 2 monster.
- The caller of `FUN_0056f7f0` that passes the level to the do (`FUN_005cb0c0`) was not found: 0x5a6000..0x5a8000 has only the three `FUN_0056ecb0` call sites (0x5a6d2d, 0x5a6db9, 0x5a7181) and no call of `FUN_0056f7f0` (it is reached some other way). So "the level the shaman's do gets is the unit's skill level" is I, not V; the live drill S1 reads it.
- No reader of `rangedtype` in game.exe was searched: that the game's thinks ignore the column is U (the thinks above are chosen by AI name, not by the column).
- Not run: the Bighead, Skeleton Mage, Sand Raider, Scarab, Sand Leaper thinks in this card (S or U in the table); `FUN_005fd470` itself on a scene (D1).
- Quill Rat, Fallen Shaman, Skeleton Archer scenes carry the monsterai caveats (no leader command for the Quill Rat, scene values for the corpse): see monster-ai-trace L1 and monsterai2 L2.
