## Why

The user asked (2026-11-01) for branding materials for d.idle: icon, header image, ASCII logo. The project has no brand assets yet.

## What Changes

- assets/branding/concepts/{cursor,rune,tick}/: three original concept directions (logo, mark, icon, header, ASCII, palette), all drawn as shapes (own pixel font), no third-party fonts or images.
- assets/branding/gen.py: the stdlib generator that writes them; assets/branding/concepts/index.html: contact sheet.
- docs/branding.md: concepts, recommendation, usage rules, application checklist.
- Nothing is applied to the README, web pages, GitHub or Discord: each application needs the user's go.
